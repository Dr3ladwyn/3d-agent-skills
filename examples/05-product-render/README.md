# Product Render Workflow

## Goal

Create a professional product visualization using AI-managed CG workflows.

## Pipeline

1. Reference analysis
2. Asset preparation
3. Materials
4. Studio lighting
5. Camera composition
6. Render optimization
7. Quality review

## Agents

- CG Supervisor
- Modeler
- LookDev Artist
- Lighting Artist
- Render Supervisor

## Evaluation

The final output must pass:

- composition checks
- material realism checks
- lighting readability checks
- render quality checks

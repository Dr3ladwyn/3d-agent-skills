# Character Production Example

Goal: Create a production-ready character asset.

Workflow:

1. Reference analysis
2. Character blockout
3. Sculpting
4. Retopology
5. UV preparation
6. Materials
7. Lighting
8. Quality evaluation

Agents:

- CG Supervisor
- Character Artist
- Sculptor
- LookDev Artist
- QC Reviewer

The final output must pass asset-quality evaluation.

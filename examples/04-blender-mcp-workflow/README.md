# Blender MCP Workflow Example

## Goal

Connect an AI agent to Blender through MCP and execute a production workflow.

## Flow

Task

→ CG Supervisor

→ Blender MCP

→ Scene Operations

→ Inspection

→ Quality Review

## Recommended Operations

- create assets
- inspect scene
- modify materials
- configure camera
- validate render

The MCP layer provides execution. The production skills provide decision making.

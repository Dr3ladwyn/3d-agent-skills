# Installation

## Clone

```bash
git clone https://github.com/Dr3ladwyn/3d-agent-skills
cd 3d-agent-skills
```

## Harness Integration

Supported targets:

- Claude Code
- Codex
- OpenCode
- Cursor
- Cline
- Roo Code

## Install Skills

Use the 3das CLI:

```bash
3das install blender
```

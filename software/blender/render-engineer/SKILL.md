# Blender Render Engineer Skill

## Role

Senior Rendering Technical Director.

## Responsibilities

- Configure Cycles and Eevee workflows
- Optimize GPU rendering
- Validate lighting and exposure
- Detect artifacts
- Prepare final delivery

## Workflow

1. Analyze target output
2. Validate camera
3. Configure render engine
4. Optimize samples and performance
5. Review image quality
6. Approve final render

## Quality Checks

- No visible artifacts
- Correct color management
- Balanced exposure
- Production-ready output

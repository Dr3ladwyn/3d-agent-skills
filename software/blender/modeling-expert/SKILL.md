# Blender Modeling Expert

## Role
Senior 3D Modeler specializing in production-ready assets.

## Responsibilities
- Hard surface modeling
- Organic modeling
- Clean topology
- Non-destructive workflows
- Asset preparation

## Workflow

1. Analyze references
2. Define proportions and scale
3. Create blockout
4. Refine primary forms
5. Add secondary details
6. Validate topology
7. Prepare for materials

## Quality Checks

- Correct silhouette
- Clean edge flow
- Proper normals
- Efficient polygon usage
- Production-ready naming

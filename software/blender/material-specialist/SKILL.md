# Blender Material Specialist Skill

## Role

Look development and physically based material specialist.

## Responsibilities

- Create realistic shaders
- Analyze reference materials
- Control roughness and surface response
- Maintain material consistency

## Workflow

1. Analyze reference
2. Identify physical properties
3. Build shader
4. Test under lighting
5. Validate realism

## Quality Checks

- Correct scale
- Realistic response
- No flat materials
- Consistent texel and detail quality

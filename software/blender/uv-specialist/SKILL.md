# Blender UV Specialist

## Mission
Create production-ready UV layouts for assets.

## Workflow
1. Analyze asset visibility and texture requirements.
2. Create logical seams.
3. Maintain consistent texel density.
4. Minimize stretching.
5. Prepare UVs for baking and texturing.

## Quality Gates
- No visible stretching.
- Correct UV scale.
- Clean island organization.
- Ready for texture baking.

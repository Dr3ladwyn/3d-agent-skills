# Blender LookDev Artist

## Mission
Develop physically believable materials and visual appearance.

## Workflow
1. Analyze reference materials.
2. Define shader properties.
3. Build PBR materials.
4. Add controlled imperfections.
5. Validate under final lighting.

## Quality Gates
- Correct roughness response.
- Realistic surface behavior.
- Consistent material language.

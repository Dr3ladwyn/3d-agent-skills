# 3D Agent Skills CLI

Planned command-line interface for managing AI CG skills.

## Planned commands

```bash
3das install blender-character-artist
3das install cg-supervisor
3das list
3das update
3das doctor
```

## Goals

- Install skills into supported AI harnesses
- Detect available environments
- Manage skill versions
- Validate installation

## Supported Targets

- Claude Code
- Codex
- OpenCode
- Cursor
- Cline
- Roo Code

# Contributing to 3D Agent Skills

Thank you for contributing.

## Skill Requirements

Every skill should contain:

- Role definition
- Production goal
- Workflow stages
- Quality standards
- Common mistakes
- Validation checklist

Skills should describe professional workflows, not simple software instructions.

## Quality Standard

Write skills as if they will train a senior CG artist AI agent.

Prioritize:

- real production pipelines
- repeatable workflows
- measurable quality checks
- industry terminology

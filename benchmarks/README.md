# 3D Agent Benchmarks

Evaluation framework for AI agents working on CG production tasks.

## Purpose

Measure whether an AI agent can produce professional 3D work instead of only executing Blender commands.

## Benchmark Categories

- Character creation
- Environment production
- Hard surface assets
- Materials and look development
- Lighting
- Final rendering

## Evaluation Areas

Each benchmark evaluates:

- artistic intent
- reference matching
- technical quality
- production readiness
- iteration ability

## Future

Benchmarks will provide standardized tests similar to software engineering agent evaluations, adapted for computer graphics workflows.

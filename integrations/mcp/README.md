# MCP Integration Layer

## Goal

Connect production AI agents with digital content creation tools.

## Architecture

```
AI Agent
   |
   v
MCP Layer
   |
   +-- Blender
   +-- Unreal Engine
   +-- Houdini
   +-- ZBrush
```

## Principles

MCP integrations should expose production capabilities, not only UI automation.

Agents should understand:

- scene structure
- asset pipelines
- validation
- rendering workflows
- export requirements

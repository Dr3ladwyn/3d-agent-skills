# AI Harness Integration Guide

## Goal

Make 3D Agent Skills available inside coding agents that support custom skills.

## Recommended workflow

1. Install repository.
2. Add skill directory to harness configuration.
3. Restart agent.
4. Ask agent to use the CG Supervisor workflow.

## Example requests

```
Create a production-ready Blender character workflow.
```

```
Review this 3D asset using the QC Supervisor skill.
```

```
Plan this environment scene using the Environment Artist agent.
```

## Architecture

The harness provides execution.

3D Agent Skills provides professional CG reasoning.

# 3D Agent Skills v1.0.0 Release

## Overview

3D Agent Skills is a production framework for AI agents working in computer graphics.

The project provides:

- professional CG workflows
- specialized AI artist roles
- production pipelines
- evaluation standards
- software integrations

## Supported Concepts

- Blender workflows
- Character creation
- Environment art
- Materials and look development
- Lighting
- Rendering
- Quality control

## Goal

Transform AI agents from tool operators into production-aware CG collaborators.

# 3D Agent Skills Architecture

## Overview

3D Agent Skills is organized as a production framework rather than a prompt collection.

```
User Task
   |
   v
CG Supervisor Agent
   |
   +-- Specialist Agents
   |
   +-- Production Skills
   |
   +-- Pipeline Definitions
   |
   v
DCC Software + MCP Integrations
```

## Layers

### Core
Production reasoning and orchestration.

### Agents
Roles matching professional CG teams.

### Skills
Reusable expert workflows.

### Pipelines
Stage-based production recipes.

### Standards
Quality gates and evaluation rules.

### Integrations
Connections to Blender, DCC tools and AI harnesses.

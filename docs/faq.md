# Frequently Asked Questions

## What is 3D Agent Skills?

A production framework that teaches AI agents professional CG workflows instead of simple software commands.

## Is this only for Blender?

No. Blender is the first supported DCC. The architecture supports ZBrush, Houdini, Unreal Engine and other production tools.

## Does it replace artists?

No. It encodes expert workflows so AI agents can collaborate with artists and automate repetitive production tasks.

## Which agents are supported?

The skills format is designed for Claude Code, Codex, OpenCode, Cursor and other harnesses that support instruction-based agents.

## What makes this different from Blender MCP projects?

MCP provides tool access. 3D Agent Skills provides production knowledge, roles, workflows and quality standards.

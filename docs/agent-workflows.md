# AI Agent Workflows

## CG Supervisor Workflow

The recommended autonomous workflow:

1. Analyze creative goal
2. Study references
3. Select specialist skills
4. Create production plan
5. Execute stages
6. Validate quality
7. Iterate until approved

## Specialist Selection

Character task:

- character artist
- sculptor
- retopology
- materials
- quality control

Environment task:

- environment artist
- hard surface
- lookdev
- lighting
- rendering

The agent should behave like a professional CG studio pipeline, not a simple automation script.

# AI Harness Integration

3D Agent Skills uses a portable SKILL.md format compatible with modern AI coding harnesses.

## Supported

- Claude Code
- Codex
- OpenCode
- Cursor
- Cline
- Roo Code

## Installation concept

Clone repository:

```bash
git clone https://github.com/Dr3ladwyn/3d-agent-skills
```

Copy required skills into the harness skill directory.

## Agent workflow

Harness
→ Skill discovery
→ CG Supervisor
→ Specialist selection
→ Production workflow
→ Quality evaluation

The goal is to provide domain expertise, not only software commands.

# Harness Installation Guide

## Supported AI Coding Harnesses

The framework is designed around portable skill definitions.

Supported targets:

- Claude Code
- Codex
- OpenCode
- Cursor
- Cline
- Roo Code

## Installation Concept

Install the repository, then copy or link skills into the harness skill directory.

Example:

```bash
3das install --harness claude-code
```

## Verification

After installation verify:

- skills are discoverable;
- registry is valid;
- workflows load correctly.
